# AuraSeal requirements

AuraSeal implements the AgentVerse’26 PS-01 Certificate Agent workflow. The supplied traceable roadmap defines the requirements and G0 through G7. Work advances in dependency order without calendar waits.

| Phase | Outcome | Gate |
|---|---|---|
| P0 | Requirements, data contracts, synthetic fixtures and CI | G0 |
| P1 | Organizer access, events and trusted CSV/XLSX results | G1 |
| P2 | Accessible cinematic certificate composition | G2 |
| P3 | Bounded OpenAI planning and record-backed issuance | G3 |
| P4 | Durable exports, verification QR, download and LinkedIn share | G4 |
| P5 | 50-row issuance, retry and progress | G5 |
| P6 | Authorization, privacy, accessibility and recovery rehearsal | G6 |
| P7 | User-selected hosting, external smoke test, demo and team submission | G7 |

Organizer approval is required for issuance. AI receives tier counts and rank availability, and selects approved copy and themes. The public record reveals the approved display name, event, issuer, tier and disclosed rank. Synthetic fixtures use a fictional issuer and contain no official logos. Team eligibility, submission and gate sign-off require confirmation from the registered team.
